# 売上CSVで今月をふり返るボード（sales-month-board）

売上のCSVを選ぶか、Excel・スプレッドシートの表を貼ると、今月の合計・先月の同じ日数までとの比較・1日あたり・一番売れた日・日ごとの棒グラフ・曜日ごとの1日平均・よく売れた物トップ5を1画面に出す1ページの道具です。結果は1枚の画像（1080×1350）で保存できます。

- **CSVはブラウザの中だけで集計し、保存も送信もしません。** この端末に残すのは、どの列を日付・金額として使うかの選び方だけです（localStorage。見出しの文字そのものは残さず、見出しから作った短い符号と列の番号を残します）。閲覧数の計測に Cloudflare Web Analytics を使っています
- 日付の列と金額の列を見出しの言葉と中身から推測します。外れたら選び直せます。見出しで決まらず中身から選んだときは、画面で確かめるよう案内します。実在のレジ・ネットショップのCSVでは試していません
- 先頭に題名や期間の行があるCSVは、日付が読める最初の行の1つ上を見出しとみなし、それより上を読み飛ばします
- 「前の月の同じ日数まで」と比べるのは、データの中で一番新しい月が、まだ終わっていない（端末の今日がその月の中にある）ときだけです。前の月のデータが途中の日から始まっているときは比べません
- 時刻のタイムゾーンは見ません（`2026-10-01T23:30:00Z` は10月1日として数えます）
- 文字コードはUTF-8（BOMあり・なし）とShift_JIS、区切りはカンマとタブに対応しています
- 金額はCSVの値をそのまま足します（税込・税抜は見分けません）。合計の行と明細の行が混ざっているCSVは、金額が二重になります
- 「良い」「悪い」の判定や予測はしません。比べた数字だけを出します
- 祝日は2025〜2027年の国民の祝日（振替休日・国民の休日を含む）だけを持っています
- 見本のデータは架空の「カフェ みほん」です（乱数ではなく決まった式で作ります。期間は、今日の前日までの今月と、まるごとの前の月です）
